# Veyra: данные и внешние сервисы

По умолчанию профиль браузера хранится на устройстве. Windows использует `%APPDATA%/Veyra`, Android — приватное хранилище приложения. История, настройки и закладки локально не зашифрованы; менеджер паролей Windows имеет отдельное шифрованное хранилище. Удаление приложения/профиля может удалить данные.

Синхронизация необязательна и запускается пользователем. Аккаунты и сессии обслуживает собственный API Veyra на Cloudflare Workers. Supabase используется как база PostgreSQL, без Supabase Auth. Сервер хранит email, bcrypt-хеш пароля, хеши сессий, служебные метаданные и зашифрованные копии закладок. Пароль аккаунта передаётся по HTTPS для проверки; в базе открытый пароль не сохраняется. Сессии действуют до 30 дней и сохраняются на устройстве через шифрование Windows или Android Keystore. Можно выйти со всех устройств, сменить пароль или удалить аккаунт в разделе синхронизации.

Копии закладок шифруются на устройстве AES-256-GCM с отдельной пользовательской фразой (PBKDF2-SHA256, 600 000 итераций). Эта фраза серверу не передаётся и не восстанавливается через почту. Сервер видит аккаунт, случайный ID устройства, платформу и время передачи. Пароли сайтов, cookie и история в копию не включаются. Удаление аккаунта удаляет его облачные копии и сессии; местный профиль сохраняется. Записи старого входа Supabase автоматически в новый аккаунт не переносятся.

Cloudflare и Supabase обрабатывают запросы и сетевые данные в своей инфраструктуре. Brevo получает email и одноразовый код для подтверждения адреса и восстановления пароля; код действует 10 минут, число попыток ограничено. Почтовая отправка ограничена бесплатной квотой. Служебные счётчики ограничивают частоту запросов; IP для этих счётчиков хешируется с серверным секретом. Политики внешних провайдеров также применяются.

Проверка обновлений обращается к GitHub; скачивание файлов — к GitHub и его инфраструктуре раздачи. Списки фильтрации Windows могут обновляться через easylist.to, если включено обновление фильтров. Открываемые сайты и выбранная поисковая система получают обычные сетевые запросы. Discord Rich Presence передаёт статус локальному Discord только при включении функции; показ домена настраивается отдельно.

Veyra не предоставляет VPN и не скрывает IP-адрес. Вход через Google зависит от требований Google и движка: универсальная совместимость со всеми способами входа не гарантируется.

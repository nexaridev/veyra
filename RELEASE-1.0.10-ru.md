# Veyra 1.0.10 quick fix

Этот выпуск для Windows исправляет меню настройки главной страницы и восстановление вкладок. Панель Customize открывается одним действием, на главной остаётся одна кнопка Done, фоновые вкладки восстанавливаются по одной с учётом порога памяти. Android остаётся на версии 0.7.2.

Проверки: `npm test`, сборка Windows, распаковка release ZIP штатным установщиком. Исполняемые файлы Windows не подписаны Authenticode.

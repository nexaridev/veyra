# Veyra для Android 0.7.0

- Добавлены запросы разрешений сайтов для камеры, микрофона и демонстрации экрана с выбором устройства или источника.
- Добавлены выбор файлов на сайтах и сохранённый список загрузок.
- Добавлены управление профилем и устройствами, недавние запросы и перемещаемые виджеты главной страницы.
- Добавлено восстановление выбранной вкладки после сбоя процесса без автоматической перезагрузки фоновых вкладок.
- Добавлены категории настроек и сочетания клавиш для физической клавиатуры.

APK подписан действующим ключом Veyra. Повторно установить обновление на телефон не удалось: во время упаковки устройство отключилось от ADB.

# Windows 0.8.0 и Android 0.6.0

На Windows появился Veyra Studio: `veyra://widget-studio`. Собирай виджеты на холсте из текста, фигур, изображений, часов и кнопок. Элементы можно двигать, менять их размеры, цвета и порядок слоёв. Есть отмена действий, черновик и шаблоны часов, календаря и списка дел.

Пакеты `.veyrawidget` можно импортировать, экспортировать и публиковать. Собственные HTML, CSS и JavaScript запускаются в изолированном окне без доступа к сети, аккаунту, файлам, cookie и интерфейсу браузера. Перед публикацией нужно отдельно подтвердить, что весь код, текст и изображения пакета станут общедоступными. Встроенные заметки и недавние запросы остаются локальными.

Виджеты свободно размещаются на рабочем столе новой вкладки. Кнопка «Редактировать» включает перемещение и изменение размеров, «Готово» возвращает обычный режим. Сохранение позиции не перезагружает работающий виджет.

На обеих платформах появились аватары и двухфакторная защита через приложение. Подключение завершается только после проверки кода. Десять одноразовых резервных кодов показываются один раз. Включение защиты и изменение резервных кодов завершают другие сеансы. Сервер проверяет второй фактор при входе, восстановлении пароля и изменении безопасности. QR-код Windows создаётся локально. Android может открыть установленное приложение или показать ключ для ручного ввода.

Подтверждение регистрации теперь также проверяет выбранный пароль. Старый путь синхронизации соблюдает ограничение числа копий. Данные аккаунтов и браузера сохраняются на прежних местах.

## Проверка

Проверены редактор, отмена действий, свободное перемещение, сохранённые позиции и изоляция кода в Electron. Профиль, подключение 2ФА и вход с резервным кодом проверены через настоящий интерфейс и API на временном аккаунте, который затем удалён.

Транзакционные тесты базы проверяют стандартные векторы TOTP, подключение 2ФА, защиту от повторного кода, одноразовые резервные коды, их замену, восстановление пароля, отзыв сеансов, аватары, владельцев публикаций, регистрацию и лимиты старой синхронизации. Тестовые данные откатываются. Android собирается и проходит Lint с прежним ключом подписи.

Независимая проверка исходников бэкенда выявила две слабости старых сценариев регистрации и хранения. Обе исправлены перед развёртыванием. Проверка не гарантирует отсутствие всех возможных уязвимостей.

## Ограничения

Визуальный конструктор и собственные исполняемые пакеты в этом выпуске доступны на Windows. Android сохраняет встроенные виджеты и получает аватары и защиту аккаунта. Сетевые разрешения пакетов пока не поддерживаются. Опубликованный пакет раскрывает весь свой текст и изображения. Для постоянных заметок используй встроенный виджет.

Проверка на физическом Android ещё нужна. Проверенной и нотарифицированной сборки macOS нет. Windows не подписана Authenticode. Google может отклонять встроенный движок. VPN в выпуск не входит.

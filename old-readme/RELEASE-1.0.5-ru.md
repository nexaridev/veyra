# Veyra 1.0.5 — тестовая версия для Windows

Это предварительная сборка для тестирования. Стабильный канал обновлений не переключается.

- Исправлена повторная регистрация обработчиков протокола виджетов после очистки их данных.
- Исправлено переполнение элементов разрешений в панели редактора виджетов.
- Добавлена возможность вручную подтвердить попытку открытия ссылки приложения, если Windows не определила обработчик протокола. Для нераспознанного приложения постоянное разрешение не сохраняется.

Ограничения Google при входе не менялись. Некоторые провайдеры отклоняют вход во встроенном браузере; используйте поддерживаемый ими сценарий входа, если он доступен.

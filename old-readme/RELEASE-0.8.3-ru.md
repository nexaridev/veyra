# Veyra 0.8.3 для Windows

Для интерфейса браузера отключено фоновое ограничение таймеров и анимации, когда его область перекрывают представления сайтов. Это устраняет возможную причину задержки отображения нажатий до переключения вкладки.

Проверены настройка интерфейса в рабочем коде, выполнение кадров анимации при открытой странице, передача результатов и закрытие всплывающих вкладок. Точное зависание на устройстве пользователя пока не воспроизведено.

Обновление не устраняет отказ Google для встроенных браузеров. Режим совместимости не гарантирует вход Google. Android остаётся версии 0.6.1, инструменты установки версии 1.3.1.

Закрытие браузера безопасно обрабатывает вкладки, для которых нативное содержимое уже уничтожено, без TypeError в главном процессе.

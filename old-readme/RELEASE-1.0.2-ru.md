# Veyra 1.0.2 для Windows

Добавлено открытие локальных HTML: Ctrl+O, пункт «Открыть HTML-файл» в меню, перетаскивание на верхнюю панель или главную страницу, путь в адресной строке и передача файла в Veyra.exe. Veyra регистрируется в Windows как вариант «Открыть с помощью» для .html и .htm, не меняя текущий выбор приложения по умолчанию.

Для каждой папки проекта используется отдельная сохраняемая сессия. Работают относительные CSS, JavaScript и картинки. Локальным страницам недоступны внутренний интерфейс Veyra и Node.js. Ресурсы разрешены только внутри выбранной папки проекта; внутренние файлы приложения, профиль, AppData и сетевые UNC пути закрыты. Разрешения камеры и других устройств локальным страницам не выдаются. Локальные HTML вкладки автоматически при запуске не восстанавливаются. Если открыт сайт, перетаскивай файл на верхнюю панель браузера.

Проверено на настоящем проекте «Тихое место»: HTML, CSS, JavaScript, посадки и localStorage, отсутствие привилегированных API, блокировка внутренних файлов и других папок, Ctrl+O и передача файла уже запущенному браузеру. Пройдены проверки аккаунта, всплывающих окон и закрытия браузера. Windows 1.0.2 сохраняет Discord поддержку и функции 1.0.1. Android остаётся 0.6.6, служебные программы 1.3.1. Совместимость Google остаётся экспериментальной.

# Veyra для Windows 1.0.7

- Добавлены запросы разрешений сайтов для камеры, микрофона и демонстрации экрана. Можно выбрать источник и отдельно разрешить системный звук.
- Чтение буфера обмена теперь требует подтверждения: перед передачей показан текст, его можно разрешить или отменить.
- Добавлено зашифрованное хранение платёжных карт в локальном хранилище паролей.
- Исправлено восстановление чрезмерно разросшихся данных uBlock Origin с сохранением cookie и сеансов сайтов.
- Ограничена автоматическая перезагрузка после завершения процесса страницы, чтобы фоновые вкладки не создавали повторную нагрузку.
- Установщик, лаунчер и удаление обновлены до версии 1.3.3.

Сборка Windows не подписана Authenticode. Windows может показать стандартное предупреждение для нового издателя.

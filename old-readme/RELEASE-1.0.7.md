# Veyra for Windows 1.0.7

- Added user controlled website access prompts for camera, microphone, and screen sharing, including source selection and optional system audio.
- Clipboard reads now ask before sharing text with a website. The user can approve the displayed text or cancel.
- Added encrypted payment card storage in the local password vault.
- Fixed oversized uBlock Origin profile data recovery while preserving website cookies and sessions.
- Reduced automatic recovery work after a renderer process exits, preventing repeated background reloads.
- Updated the installer, launcher, and uninstall tool to version 1.3.3.

The Windows build is not Authenticode signed; Windows may show its usual warning for a new publisher.

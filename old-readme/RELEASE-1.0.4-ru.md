# Veyra 1.0.4 для Windows

Добавлены явные разрешения для изолированных виджетов сообщества. Перед установкой Veyra показывает запрошенные HTTPS-домены и необходимость отдельного локального хранилища, затем просит подтверждение. Предпросмотр не получает этих прав. Сеть ограничена fetch/XHR-запросами к точно указанным HTTPS-доменам; хранилище изолировано для каждого виджета. Cookie, данные профиля браузера, файлы, буфер обмена и аккаунт остаются недоступны. Серверная проверка публикаций Supabase теперь принимает только этот формат разрешений.

Android остаётся 0.6.6.

# Veyra 1.1.0 для Windows и Android 0.7.3

Доступны Windows 1.1.0 и Android 0.7.3. Основная кнопка загрузки на сайте скачивает установщик Windows, ZIP-архив оставлен дополнительной ссылкой.

## Windows

- Добавлена регистрация Windows-обработчиков поддерживаемых документов и изображений. Veyra предлагает обработчики, не меняя выбор приложений по умолчанию без согласия пользователя. При удалении очищаются только записи Veyra.
- Добавлена настройка типов файлов в диалоге Ctrl+O. HTML, XHTML, XML, SVG, текст, PDF и изображения открываются в отдельных вкладках; поддерживается перетаскивание файлов.
- Обновлён выбор поисковой системы и настройки совместимости.
- Установщик 1.3.5 регистрирует обработчики файлов и удаляет только принадлежащие Veyra записи.

## Android

- Обновлён браузер на GeckoView до 0.7.3, в том числе обработка касаний и состояния видимости страницы.
- Категории настроек и мобильные элементы управления стали удобнее.

## Загрузки

- Установщик Windows: `VeyraSetup.exe` из релиза `installer-v1.3.5`.
- Архив Windows: `Veyra-1.1.0-Windows.zip`.
- Android: `Veyra-Android-0.7.3.apk`.
- Контрольные суммы SHA-256 находятся в `SHA256SUMS.txt`.

Маршрут сайта `/download/windows` ведёт на установщик. ZIP доступен отдельно для ручной или переносной установки. Манифест обновлений браузера подписан закреплённым ключом Ed25519.

Релиз не гарантирует совместимость каждого сценария входа Google и не заявляет универсальную гарантию отсутствия утечек памяти. Для воспроизведения проблемы приложите страницу и измерения памяти процессов.

# Veyra 1.0.1 для Windows

Возле версии браузера появился значок Discord. Он открывает [сервер поддержки Veyra](https://discord.gg/29m8etyA9R) в новой вкладке. Кнопка доступна в главном меню и в разделе «Настройки → О браузере». Подсказка и подпись для скринридера переведены на русский и английский. Ссылка на сервер также добавлена в README на GitHub.

Сохранены функции 1.0.0: подтверждение открытия внешних приложений и копирование чистых ссылок. Android 0.6.6 также получил значок сервера поддержки возле версии в настройках, с подписями на русском, английском и украинском. Идентификатор приложения и сертификат подписи сохранены для обновления поверх предыдущей версии. Установщик, лаунчер и Delete Veyra остаются версии 1.3.1 и получают новую версию браузера через подписанную ленту обновлений. Данные профиля сохраняются.

Проверка: тест интерфейса Chromium проверил оба расположения значка, подписи RU/EN и существующие сценарии аккаунта, всплывающих окон и закрытия браузера. Проверены файлы готовой сборки и номер версии. После публикации проверены контрольные суммы релиза, подписанная лента, сайт RU/EN и ссылки скачивания.

Совместимость Google остаётся экспериментальной: принятие входа сервисом не гарантируется. [Функции и ограничения 1.0.0](https://github.com/nexaridev/veyra/blob/main/RELEASE-1.0.0-ru.md). Сервер аккаунтов и база данных в этом выпуске не менялись.

Android 0.6.6 собран и прошёл release Lint. Подпись APK проверена: сертификат совпадает с 0.6.5, код версии 10, отладка отключена. Интерфейс на физическом телефоне не проверялся.

# Veyra 1.0.11a

Быстрый выпуск для Windows. Поиск на главной теперь оформлен по примеру Firefox: компактный выбор поисковика, полноширинный список посещённых сайтов с локальными favicon и отдельный блок недавних поисков. Сторонние favicon-сервисы не используются. Сайт загрузки получил английский язык по умолчанию, выбор из пяти языков (English, Русский, Українська, Deutsch, Polski), адаптивную анимацию и поддержку системного уменьшения движения.

Android остаётся на версии 0.7.2. Сборка macOS не входит в Windows-релиз: универсальный DMG можно создать на Mac командами `npm ci`, `npm run build:mac` и `npm run build:mac:dmg`. Приложение пока не подписано и не нотариализовано.

Проверка: `npm test`, изолированные проверки интерфейса в Electron, сборка Windows, извлечение архива существующим установщиком, локализация и рендер сайта, Wrangler dry-run и SHA-256.

# Veyra 0.8.2 для Windows и Android 0.6.1

Окна сайтов, показанные вкладками, сохраняют связь с исходной страницей, передачу результата и cookie-профиль при переходах во время входа. Закрытие из скрипта удаляет вкладку и возвращает к исходной. Поддерживаются окна, открываемые сначала как about:blank. Вкладки таких окон не усыпляются во время входа. Отдельные окна сайтов остаются необязательными.

Android обрабатывает запрос закрытия окна из скрипта и возвращается к исходной вкладке. Разрешён переход всплывающего окна через about:blank без разрешения произвольных внутренних адресов.

Проверка: локальный сценарий Windows проверяет opener, передачу результата между доменами, переход через домен совместимости, закрытие скриптом и кнопкой, пустые окна, собственные диалоги и отдельные окна. Для Android проверяются release-сборка и lint. Вход в реальный аккаунт Google не проверялся; ограничения Google для встроенных браузеров могут применяться.

Защитные заголовки сайта сохранены. Установщик, лаунчер и удаление остаются версии 1.3.1. Профили сохраняются. Исполняемые файлы Windows не имеют подписи Authenticode.

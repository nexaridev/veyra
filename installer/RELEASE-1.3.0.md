# Veyra maintenance tools 1.3.0

The launcher checks updates for the browser, setup, launcher and Delete Veyra together. A maintenance update is offered even when the browser is current. Setup verifies the signed manifest, file hash, size and executable version before passing control to the new version. Running programs are allowed to exit before replacement. Maintenance updates preserve the profile and shortcut choices. An unchanged signed browser archive is not downloaded again. Cancellation, offline launch, downgrade protection and transaction rollback are supported. The interface remains available in Russian and English.

Run this installer once over version 1.1 or 1.2 to enable future maintenance updates. Windows browser 0.7.0 and Android 0.5.0 are unchanged. Windows executables are not Authenticode signed.

## Русский

Лаунчер проверяет обновления браузера, установщика, лаунчера и Delete Veyra вместе. Обновление предлагается и тогда, когда браузер уже актуален, а служебные программы устарели или отсутствуют. Новый установщик проверяется по подписи манифеста, SHA256, размеру и версии файла. Замена начинается после закрытия предыдущего процесса. Профиль и выбор ярлыков сохраняются. Если подписанная сборка браузера не изменилась, повторно скачивать её не нужно. Доступны отмена, пропуск обновления, запуск без интернета и откат при ошибке.

Поверх версий 1.1 или 1.2 нужно один раз запустить установщик 1.3.0. После этого лаунчер сможет предлагать обновления всего комплекта. Браузер Windows остаётся 0.7.0, Android остаётся 0.5.0. Программы Windows пока не подписаны Authenticode.

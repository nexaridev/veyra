# Veyra Installer 1.3.4

This installer updates browser installs to Windows 1.0.11a and keeps the existing transactional install, SHA-256 verification, downgrade protection, rollback, and shortcut behavior.

The executable includes a pinned fallback for the 1.0.11a archive and continues to prefer newer releases from the signed update feed.

This is a manual installer update. Automatic self-update for older installed launchers requires publishing a new signed feed entry.

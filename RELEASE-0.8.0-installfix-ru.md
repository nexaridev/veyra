# Исправление установки Veyra 0.8.0 для Windows

В исходном ZIP папка называлась иначе, чем ожидает установщик. Исправленный архив содержит папку Veyra-win32-x64. Файлы браузера, версия 0.8.0 и выпуск Android не изменены.

Существующий установщик автоматически скачает исправленный архив. Закройте установщик и откройте снова, затем повторите установку. Профиль браузера сохраняется.

Перед публикацией проверяется распаковка настоящего архива выпущенным установщиком. Такая же проверка добавлена в Windows CI.

# Veyra infrastructure

Live site: https://veyra.veyra-nexaridev.workers.dev . Cloudflare Worker `veyra`, subdomain `veyra-nexaridev`, serves the site, `/privacy`, `/health`, and `POST /api/v1/{operation}`. Only free services are configured; binaries are hosted by GitHub.

Supabase project: `ekqwcwedmdpiogxskrac`, eu-west-1. New accounts use Veyra's own bcrypt passwords, opaque sessions and email-code lifecycle in private PostgreSQL tables. Supabase Auth is not used by the new apps. `supabase/accounts-v2.sql` records the initial schema; `accounts-v2-locking.sql` is the subsequent function replacement applied to the existing database. The base source also contains the final function for fresh installations. Do not reapply table creation to the existing database. Legacy `schema.sql`, Supabase Auth accounts and `public.veyra_sync` were preserved, not migrated or deleted.

The Worker uses secret bindings `ACCOUNT_GATEWAY_SECRET` and `BREVO_API_KEY`, and a public `SUPABASE_PUBLISHABLE_KEY` binding. No privileged database key is shipped in the app. The RPC validates the independent gateway secret before work; all private tables have RLS and no direct client grants. SECURITY DEFINER is intentional in this narrow authenticated gateway. Auth transitions serialize per account and revalidate sessions after locking. App config only contains the Worker URL. Bearer tokens are never returned in UI snapshots.

Brevo Free sends numeric confirmation/recovery codes from the verified sender. The free Gmail sender is rewritten by Brevo onto its shared sending domain; a custom domain was not purchased. A real delivered email and code were tested. The Brevo API key is restricted to transactional email and expires on 2027-10-22 or after provider inactivity limits; rotate it before expiration. Locally, credentials and signing keys are outside source under `%LOCALAPPDATA%/VeyraReleaseKeys`; do not publish that directory.

Operations: signup, verify, login, reset-request, reset; authenticated me, logout, logout-all, password, delete, sync-list, sync-put, sync-delete. JSON POST only. Sessions last 30 days. The API strips private mail/code fields, accepts no browser-origin cross-site requests, and derives rate-limit IP keys itself. Codes expire after 10 minutes, five attempts. A global mail cap of 150/day keeps below the free mail quota. Login attempts are limited by email, requests by IP. Each account has at most 10 device copies, up to 2 MiB each. Synchronization is manual and bookmark-only, encrypted on clients with a separate phrase. Operational maintenance should periodically remove expired codes and old rate counters; verified accounts and backups must not be purged by that maintenance.

GitHub: https://github.com/nexaridev/veyra . Windows 0.6.1 / Android 0.3.0 test artifacts and signed update manifest are prepared separately from the older draft. Physical Android acceptance remains outstanding; see `RELEASE-0.6.1.md`. Windows updates verify and download a ZIP; installation is manual. Android update checking is not implemented yet.

R2 is not enabled in the Cloudflare account and is optional while GitHub hosts binary assets. No paid resource upgrade was requested or enabled during preparation.

# Veyra 1.1.3

Релиз браузера для Windows и Android 0.7.5.

## Изменения

- В настройках появился отдельный раздел «Приватность»: защита от отслеживания, политика WebRTC, буфер обмена и совместимость фокуса/fullscreen.
- В новых профилях по умолчанию включён Sandbox Clipboard Mode. При обновлении ранее сохранённый режим буфера сохраняется. Настройка применяется к открытым вкладкам без перезагрузки.
- Shift + правая кнопка мыши открывает контекстное меню Veyra, даже если сайт блокирует своё меню. Перехватывается только этот явный жест; обычный щелчок правой кнопкой не меняется.
- Слой подсказок адресной строки поднят над соседними элементами панели.
- Запросы синхронизации и обновлений проходят через сетевой стек Chromium; локальные HTML-файлы используют общую фильтруемую сессию.
- Обновлены метаданные релиза сайта и резервная версия установщика.

## Примечания

Sandbox Clipboard Mode выполняет системные действия копирования, вырезания и вставки через браузер. Сайт не получает эти события. В редакторах форматированного текста может потеряться форматирование; режим можно переключить в настройках.

Автоматические обновления Windows требуют действительной подписанной манифестной записи. Старый подписанный канал в этом изменении не заменён: ключ его подписи недоступен. Для установки используйте установщик из релиза или проверенный ZIP-архив.

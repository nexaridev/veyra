# Veyra 0.9.0 для Windows и 0.6.5 для Android

## Производительность Windows

Исправлено рекурсивное переключение вкладок в адаптере расширений. Оно могло приводить к переполнению стека, повторным обновлениям состояния и зависанию кнопок браузера. uBlock Origin запускается при открытии сайта. Инициализация профилей выполняется последовательно, без запуска двух фильтрующих движков до появления пустого главного экрана.

Неизменённые стандартные часы и дата, а также визуальные виджеты без своего кода теперь используют обычные элементы интерфейса. Четыре аналоговых часа не создают гостевых web contents. Свой HTML и JavaScript остаются в изоляции. Предпросмотр повторно использует уже созданный процесс. При уходе со страницы освобождаются документы, наблюдатели и гостевые представления. Виджеты со своим кодом вне видимой области выгружаются через 30 секунд и запускаются заново при появлении; их временное состояние при выгрузке не сохраняется.

В локальном тесте с чистым профилем и четырьмя аналоговыми часами медиана суммарного рабочего набора снизилась с 2286 до 538,5 МБ, число процессов с 14 до 4. Пик за весь сценарий снизился с 2368 до 647 МБ. Пустое окно появилось примерно через 0,4 секунды вместо 4,5. Результаты не гарантируют такой же расход на любых сайтах, устройствах и пользовательском коде. Случай с расходом 8 ГБ в точности не воспроизведён. Целевой объём ОЗУ остаётся мягким ориентиром.

Панель производительности отдельно показывает суммарный рабочий набор, частную память и число процессов. Учёт общей памяти может отличаться от диспетчера задач.

## Разрешения и уведомления

Запросы камеры, микрофона, уведомлений и других поддерживаемых разрешений показываются в интерфейсе Veyra. Камеру и микрофон можно разрешать отдельно. После разрешения доступа можно выбрать доступные устройства до передачи потока сайту. Для получения названий устройств сначала создаётся управляемый браузером поток; при отмене или замене он останавливается. Временные разрешения сбрасываются при переходе страницы. Запросы привязаны к документу и источнику.

Настроены идентификатор приложения и ярлык в меню «Пуск» для системных уведомлений сайтов. Проверены разрешения и параметры ярлыка; появление настоящего системного уведомления вручную не проверялось. Браузер должен быть запущен. Доставка push после полного выхода не обещается.

## Android 0.6.5

Восстановленные фоновые вкладки больше не открываются и не загружаются одновременно при запуске. Загружается выбранная вкладка, остальные ждут выбора. При повторных переходах сохраняется поверхность GeckoView. Частые сохранения истории, вкладок и виджетов объединены; перед сворачиванием и уничтожением окна ожидающие изменения сохраняются. На главном экране обычная страница не остаётся активной, если для неё не включено «Не усыплять».

APK собран и прошёл Android Lint. Сохранены идентификатор приложения и сертификат подписи, увеличен код версии. Подключённого Android устройства для замера плавности и приёмочной проверки не было. Скорость сайтов зависит от соединения и самих страниц.

## Проверки и ограничения

Пройдены проверки отрисовки и освобождения виджетов, повторных переходов, переиспользования предпросмотра, изоляции, фильтрации uBlock, переключения вкладок, жизненного цикла всплывающих окон, привязки разрешений к источнику и выбора тестовых камеры и микрофона. Изоляция виджетов по прежнему закрывает сеть, Node и данные браузера.

Windows версии с 0.7.0 по 0.8.3 помечены предупреждением о памяти. Для повседневной работы следует обновиться. Отказ Google с сообщением о небезопасном браузере остаётся отдельной проблемой совместимости; этот выпуск не заявляет его исправление.

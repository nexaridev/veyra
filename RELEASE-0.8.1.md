# Veyra 0.8.1 for Windows

Custom widgets now fill their card correctly. In edit mode, the title and settings bar appears on hover or keyboard focus. SVG and HTML content can be selected as a code layer, moved and resized in the visual builder. SVG images can also be imported as safe embedded PNG images with transparency.

The builder keeps property fields stable while editing. Editing a widget already on your home page saves it in place. Layout controls adapt to smaller windows, previews keep their aspect ratio and close cleanly, and installed widgets have a direct Edit action.

The widget store has description cards and a detail window with a preview, author, publication date, size and data access information. New publications can show the profile name after confirmation. Email addresses are never published, and older clients do not expose profile names automatically.

Setup, launcher and uninstall tools are version 1.3.1. Manual setup enables desktop and Start menu shortcuts by default, including reinstallation. Automatic maintenance updates preserve the user's choices. Browser profiles are preserved.

Android remains version 0.6.0. Both Russian and English are supported. Windows is a preview release and executables are not Authenticode signed.

Validation covered actual guest rendering sizes, SVG layer dragging, SVG image import, native widget dragging, editing without duplicates, responsive menus, isolated execution, author metadata privacy, installer rollback and upgrades from tools 1.3.0. The release archive is tested with the shipped installer before publication.

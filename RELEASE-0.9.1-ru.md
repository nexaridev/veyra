# Veyra 0.9.1 для Windows

Обычные HTTP и HTTPS ссылки из любых приложений открываются вкладками в уже запущенной Veyra. Ссылки, полученные во время запуска, ожидают готовности окна и больше не теряются.

Если сайт явно запрашивает всплывающее окно, размеры отдельного окна или Chromium сообщает запрос нового окна, открывается настоящее окно. Это работает и при выключенной настройке открытия обычных ссылок отдельными окнами. Обычные новые вкладки остаются вкладками. Сохраняются исходная сессия, связь с открывшей страницей, передача результата через postMessage и закрытие из скрипта. Настройка открытия всех новых ссылок сайтов окнами сохранена; пояснение обновлено на русском и английском.

Проверены обычные вкладки, отдельное окно по образцу входа, связь с исходной страницей и возврат сообщения, закрытие окна, передача внешней ссылки, переход из about:blank, пользовательские диалоги и завершение браузера. Использованы локальные тестовые страницы без входа в Google. Исправление не заявляет устранение отказа Google «небезопасный браузер». Оптимизация памяти из 0.9.0 сохранена.

Android остаётся 0.6.5. Инструменты установки и запуска остаются 1.3.1 и используют обновлённый подписанный канал.

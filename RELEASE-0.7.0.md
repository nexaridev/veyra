# Veyra for Android 0.7.0

- Added per-site camera, microphone, and screen sharing prompts with device/source selection.
- Added website file selection and saved downloads support.
- Added profile and device controls, recent searches, and movable home widgets.
- Added crash recovery for the selected tab while avoiding automatic reloads of background tabs.
- Added categorized settings and hardware keyboard shortcuts.

The release APK is signed with Veyra's existing Android release key. Physical device installation could not be rechecked for this release because the phone disconnected from ADB during packaging.

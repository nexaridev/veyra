# Veyra 1.0.0 для Windows

Сайты теперь могут открывать установленные приложения, например Roblox, через собственное окно подтверждения Veyra. В нём показаны сайт, зарегистрированное в Windows приложение и тип ссылки. По умолчанию выбрана отмена. Если приложение не установлено, браузер объяснит причину. Обрабатываются обычные ссылки, новые окна и ссылки из фреймов.

Разрешение можно запомнить для конкретного HTTPS сайта и типа приложения. Во временных вкладках оно не сохраняется. Чужой фрейм не получает разрешения основного сайта. Переход на другую страницу, закрытие вкладки и таймер отменяют ожидающий запрос. Разрешения можно сбросить по одному или все сразу в настройках. Полный адрес запуска с параметрами авторизации остаётся в основном процессе и не передаётся интерфейсу диалога.

Новая команда «Копировать чистую ссылку» находится в меню браузера и контекстном меню ссылки. Она убирает известные рекламные метки utm_* и fbclid, сохраняя остальные параметры, их кодирование и фрагмент. Распознанные подписанные ссылки не меняются.

Обе функции переведены на русский и английский. Экспериментальная совместимость Google сохранена. Вход в реальный аккаунт Google не гарантирован: сервис может отклонять встроенные браузеры. При проверке реальные данные входа не использовались.

## Проверка

Тесты Chromium проверили ссылки, location, window.open, iframe, подтверждение, сохранение и сброс разрешений, отсутствие приложения, фокус отмены и диалоги RU/EN. Системный запуск приложения в тестах подменён; реальная игра Roblox не запускалась. Модульные тесты проверили блокировку опасных схем, привязку к сайту, устаревшие запросы, временные вкладки и сохранность параметров чистых ссылок. Пройдены стандартные тесты, интерфейс аккаунта и проверки окон входа и совместимости Google.

Android остаётся 0.6.5. Установщик, лаунчер и Delete Veyra остаются версии 1.3.1 и получают Windows 1.0.0 через подписанную ленту обновлений. Версии Windows 0.9.1 и 0.9.2 сохранены для отката. Добавлена только настройка разрешений приложений; остальные данные профиля совместимы. Сервер аккаунтов и база в этом выпуске не менялись.

# Veyra 1.0.11

Быстрый фикс Windows: иконки сайтов теперь показываются во вкладках и ярлыках главной страницы; поиск получил подсказки по истории и запросам в стиле Firefox и выбор поисковика; категории Customize помещаются в панели; подписи раздела Performance переведены на английский; Alt+` переключает две последние вкладки надёжнее. С главной страницы убраны счётчик блокировок и бейдж Site protection, исправлена нижняя полоса.

Добавлена сборка macOS: универсальное приложение и DMG с перетаскиванием в Applications. Собирать на Mac командами `npm ci`, `npm run build:mac`, `npm run build:mac:dmg`. Приложение macOS не подписано и не notarized.

Проверено: `npm test`, сборка Windows, распаковка ZIP штатным установщиком, SHA-256. Android остаётся на 0.7.2.
